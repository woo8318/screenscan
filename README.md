# ScreenScan

폐쇄망 PC 모니터처럼 복사가 안 되는 화면의 텍스트를, 사진을 찍지 않고 카메라로 비추기만 하면서
줄 단위로 누적 추출하는 Android 앱입니다. 코드·로그처럼 들여쓰기와 줄 구분이 중요한 텍스트를 염두에 두었습니다.

## 동작 방식

- ML Kit 텍스트 인식(기기 내 처리, 오프라인)으로 카메라 프레임을 연속 분석합니다.
- 단어 좌표에서 들여쓰기, 열 정렬 공백, 빈 줄을 복원합니다 (`FrameExtractor`).
- 새 프레임을 누적 텍스트의 끝부분과 정렬해 겹치는 줄은 버리고 새 줄만 붙입니다 (`FrameMerger`).
- 자동 모드는 폰이 멈춘(두 프레임이 같은) 순간에만 병합하고, 수동 모드는 캡처 버튼으로 병합합니다.

## 사용법

1. 카메라 영역을 모니터에 비춥니다. 핀치로 줌, 탭으로 초점을 맞춥니다.
2. 자동 모드에서는 스크롤할 때마다 새 줄이 아래 텍스트 영역에 쌓입니다.
3. 일시정지 후 텍스트를 직접 고칠 수 있고, 재개하면 고친 내용이 유지됩니다.
4. 복사, 공유, 파일로 저장으로 꺼냅니다.

메뉴에서 한국어 엔진(한글 포함)과 Latin 엔진(영문 코드에 유리)을 바꿀 수 있고,
편집기 줄번호가 함께 잡히면 "줄번호 제거"를 켭니다.

## 빌드

로컬 툴체인 없이 GitHub Actions 로 빌드합니다.

- `main` 에 푸시하면 디버그 APK 가 workflow artifact 로 올라갑니다.
- `v*` 태그를 푸시하면 GitHub Release 에 APK 가 첨부됩니다.

```bash
git tag v0.1.0
git push origin main --tags
```

## 알려진 한계

- 되감기(위로 스크롤)해서 이미 지나간 곳으로 돌아가면 창 밖의 내용은 중복될 수 있습니다.
- 탭 문자는 공백으로 복원됩니다.
- 비스듬히 찍으면 들여쓰기 계산이 흔들리므로 가급적 정면에서 비춥니다.
